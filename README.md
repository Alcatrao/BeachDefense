# BeachDefense — Codex breaking surf

Praia de Mira with live breaking water, cyan sky reflections, embossed procedural wavelets, whitewater and splash crowns. Serve the repository over HTTP and open index.html. The surf button starts near the break; beach.html has whole-beach, shorebreak, tube cutaway and rider views. WASD steers, Space jumps, V changes the game view, B resets the surf and Escape pauses.

The current sea uses an eight-second moving-wall wavemaker with a slow 48-second variation in strength, a sloping inner beach and a steeper submerged sandbar. Gravity and pressure in a narrow FLIP/PIC liquid section generate the overturning lip. It starts from a simulated 24-second warm state, then evolves continuously; there is no repeating animation clip or prescribed curl trajectory. The inland tank extends 18 m onto the beach, with matching terrain, so the larger runup does not strike the old hidden wall. The finite-depth dispersion relation determines the distant analytic swell's wavelength. A 56-second development run produced repeated overturning, a peak connected crest about 2.12 m above still water and about 1.29 m of forward-folded surface. These are observed maxima, not a calibrated significant wave height or guaranteed tube diameter.

A worker extracts the connected free surface, including overhangs. It sends a 512-point profile; a fixed camera-adaptive GPU strip interpolates between snapshots at display rate. Shading normals come from the contour, with small-scale normal filtering that leaves geometry unchanged. The main thread uploads a 16 KB profile per snapshot instead of rebuilding the mesh. The character display also interpolates between physical updates. The 60 Hz fluid and 120 Hz body simulation run separately from rendering.

Character contact uses 21 samples of occupied liquid and local flow, independently of the render mesh. Buoyancy and relative-flow drag distinguish an air pocket from immersion and let lightly wetted feet plane. Water can push the character shoreward or carry it back with the flow. The view stays upright. Coupling remains one way: character momentum does not react back into the water.

Foam, wavelet textures and the twelve-frame splash crown atlas are generated once from original code. No Age of Mythology assets or owner screenshots are included. A capped instanced pool animates spray, rings and advected foam in the vertex shader. Software rendering is detected automatically: half pixel ratio, 256 profile rows, 20 coast columns, cheap normals and 128 effect slots; hardware uses 512 rows, 48 columns and 640 slots. Automated browsers never request pointer lock; manual play retains mouse capture.

This remains an approximate surf prototype. One physical section is extended along 215 m of coastline, so alongshore coherence and some broad bands remain. The section is joined smoothly to a separate analytic ocean beyond 22 m offshore; that join is visual, not a full ocean fluid solve, and contact there can disagree with the rendered blend. Foam/spray are visual tracers rather than simulated air or bubbles. The particle resolution cannot resolve every thin sheet or droplet. Headless paced rendering can test a 120 Hz workload, but cannot certify physical 120 fps presentation on the owner's display.
