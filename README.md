# BeachDefense — continuous physical surf prototype

Serve this directory over HTTP and open `index.html`. **Try beach-wide physical surf** opens the existing game with the water; **Start Game** adds defense gameplay. `beach.html` has whole-beach, tube cutaway and rider views. WASD moves, Space jumps, V changes game camera, B resets surf, Esc pauses. Skimming engages automatically, with no visible board.

Offshore FLIP/PIC liquid now runs live, without a repeated recording or loop transition. Gravity, pressure and the reef bed evolve the nearshore lip. The finite-mass character contacts live 3D water and returns opposite impulses; no proximity-triggered wave kick or prescribed tube trajectory is used. One smooth density-based surface spans the beach and the character volume, removing the previous hard mesh cut. Whitewater follows bounded foam tracers.

This remains an approximation: a narrow offshore section supplies coherent waves along 215 m of beach; the character has a separate moving 3.6 m periodic volume. Their clocks match while riding, but the character's wake does not propagate across the whole beach. Surface smoothing and the distant-plane stitch are visual approximations. Some pinched junctions, distant transition artifacts and uneven tubes remain; air and foam bubbles are not solved as a second fluid.

The longer physical wave period increased the strongest measured connected cavity height to 1.44 m (v6: 1.08 m), but its contiguous width is still only 1.08 m. A clean, long, surfable 2 m barrel is unfinished. The source stayed finite with 15,056 fixed markers through 80 simulated seconds. The matched character test tumbles in the wave and stays upright through two seconds in calm water; calm skimming ends later as speed is lost.

Six-second samples, not sustained playtest guarantees. Character contacts, surf/defense entry, pause/resume and zero page errors passed. Final rendered meshes had zero interior open edges, with some nonmanifold junctions still reported. Screenshots and measurements: `verification/v7/gpu` and `verification/v7/software`.
